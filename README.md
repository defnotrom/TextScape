# 🌌 TextScape
> *Jelajahi Dunia Baru di Setiap Baris Teks*

**TextScape** adalah game RPG berbasis teks interaktif yang didukung oleh Gemini AI sebagai Game Master. Kamu bebas menentukan arah petualangan lewat opsi pilihan atau dengan mengetik tindakanmu sendiri!

---

## 🌟 Fitur Utama

- 🎭 **Multi-Genre World:** Petualangan di dunia *Cyberpunk Detective*, *Dark Fantasy*, *Sci-Fi Space Survival*, hingga *Post-Apocalyptic*.
- 🤖 **AI Game Master Dinamis:** Narasi cerita adaptif dan konsekuensi aksi dibuat secara *real-time*.
- 🔀 **Kebebasan Bertindak:** Pilih opsi aksi bernomor atau ketik tindakan bebas tanpa batas imajinasi.
- 🔄 **Dunia Baru Kapan Saja:** Fitur reset instan di *sidebar* untuk memulai lini cerita baru.

---

## 🛠️ Teknologi

- [Python](https://www.python.org/)
- [Streamlit](https://streamlit.io/)
- [Google Generative AI SDK](https://ai.google.dev/) (Gemini 2.5 Flash)
